# Weather Text-to-SQL Chatbot (v1.0.0)

Интеллектуальный ассистент для анализа исторических данных о погоде в городах России. Проект преобразует естественный язык (русский) в SQL-запросы (DuckDB) и выполняет их напрямую к данным, хранящимся в S3-хранилище.

## 🚀 Основные возможности
- **Text-to-SQL**: Локальная LLM (Qwen 3 4B) переводит вопросы на русском языке в корректные SQL-запросы для DuckDB.
- **Прямая работа с S3**: Чтение данных из Selectel S3 через расширение `httpfs` без промежуточной загрузки.
- **Hive Partitioning**: Автоматическое извлечение колонки `city` из путей к файлам (`city=Moscow/`, `city=Chelyabinsk/` и т.д.).
- **Безопасность**: Запросы проходят валидацию (разрешены только `SELECT` и `WITH`).
- **Docker**: Полная изоляция и развертывание одной командой.

## 🛠️ Технологический стек
- **Backend**: Python 3.11, FastAPI, Uvicorn
- **LLM**: Ollama (модель `distil-qwen3-4b-text2sql`)
- **База данных**: DuckDB (In-Memory) с расширением `httpfs`
- **Хранилище**: Selectel S3 (Parquet files)
- **Инфраструктура**: Docker, Docker Compose

⚙️ Быстрый старт (Локальный запуск)
1. Подготовка переменных окружения

Создайте файл .env в корне проекта и добавьте ваши ключи доступа к S3 Selectel:
env

S3_KEY=ваш_access_key
S3_SECRET=ваш_secret_key

2. Запуск контейнеров

Убедитесь, что у вас установлены Docker и Docker Compose. Выполните:
bash

docker-compose up -d --build

При первом запуске Ollama автоматически скачает модель (около 2.5 ГБ), это может занять несколько минут.
3. Проверка работоспособности

API будет доступно по адресу: http://localhost:8000/docs (Swagger UI).
